# 数据库与迁移资料

给另一台电脑的编程助手：先完整阅读 [数据库迁移指南.md](数据库迁移指南.md)，不要猜测数据库、账号或执行清库命令。

本轮交付结果、已验证备份目录、测试口径与未完成项见 [本轮验证报告.md](本轮验证报告.md)。

本目录不是运行中的 MySQL 数据目录。账号、密码哈希、课程、作业、成绩和知识资料仍以 MySQL 为准。此处存放可迁移备份、工具及说明，不维护第二套明文账号表。

| 文件/目录 | 用途 | 是否可提交 Git |
| --- | --- | --- |
| `manage.py` | 检查、停写备份、新库恢复、内容校验 | 是 |
| `upgrade.py` | 空库初始化和历史库升级 | 是 |
| `connection.env.example` | 脱敏连接模板 | 是 |
| `数据库迁移指南.md` | 另一台电脑的完整操作指南 | 是 |
| `backups/<时间-标识>/` | SQL、附件包、校验清单，包含个人数据和密码哈希 | 否 |
| `local/` | 恢复附件暂存及本机私有资料 | 否 |
| `*.local.*` | 本地连接配置等私有文件 | 否 |
| `检索评测-*.json` | 合成开发集评测结果，无真实账号 | 是 |

备份目录已限制为当前系统用户访问；这不等于加密。跨电脑传递应使用加密介质或加密压缩包，密码另行交付。不要上传备份、真实 `.env`、SQL 内容或密码哈希到公开仓库/对话。

运行入口（在项目根目录）：

```powershell
python -X utf8 数据库/manage.py check
```

工具不回显连接密码，也不重置账号密码。管理员/师生是应用账号；MySQL 登录账号是数据库服务账号，二者不同。
