# 桌面助手交付与验证

日期：2026-09-18。按项目 skill 的计划、开发、测试、定向修复、复验步骤单助手执行；未创建/启动子智能体，未更改旧流水线状态。本报告为开发者自检，不是独立验收。

## 已交付

- 根目录 `桌面助手启动.cmd`：从任意当前目录启动，正确处理本项目中文路径。检测 Python/Tk，选择可用解释器后启动原生窗口；无需管理员权限。
- 原生桌面窗口：自动启动、运行状态、打开系统、安全停止、日志和说明入口；操作在线程中执行，界面不因构建或数据库检查而阻塞；重复窗口由操作系统文件锁拦截。
- Waitress + Vue 构建页面：统一 `127.0.0.1:5000`；关闭 debug/自动建表/公开注册，保留数据库和既有配置。前端源码变化自动重建，无变化跳过构建。
- 生命周期只管理自己创建的进程；不强杀占用端口的程序；私有管道停止，等待执行中的请求，超时取消停止；父进程管道关闭后也会尝试安全退出。
- 保留旧开发启动脚本。依赖清单 `backend/requirements-desktop.txt` 与根目录使用说明已补充。本机已安装 Waitress 3.0.2，未自动开启付费 AI worker、开机自启、系统服务或公网访问。

## 原生界面检查边界

实际观察到“作业管理系统 · 桌面助手”原生窗口及退出确认对话框，并在确认退出后从日志和端口释放确认服务停止。Tk 窗口构建测试通过。

本机截图工具返回 `SetIsBorderRequired failed: 不支持此接口 (0x80004002)`，部分鼠标输入报告 geometry unavailable；已按工具规则停止依赖截图坐标，未使用替代截图/鼠标注入。可访问性树只能完整识别标题栏和确认对话框，不能完整识别 Tk 自绘按钮。因此**完整视觉布局、缩放和逐按钮鼠标验收未标为完成**，不能把窗口出现等同于所有视觉检查通过。

## 本轮修复记录

1. 页面原来写死 localhost 与端口：改为同源路径；加载页检查数据库就绪而非仅进程存活。
2. 默认 Vite 图标缺失：替换为项目本地图标，并在静态白名单中允许。
3. 未开始迭代的响应可能滞留活动计数：在实际消费响应时计数，并补充停止测试。
4. Python 候选依赖检查可能超时：捕获并尝试下一可用解释器，不静默挂起。

## 不在本轮承诺内

- 不包括公网 HTTPS、Windows 服务、后台常驻托盘、安装包签名、开机自启或无需安装 Python 的独立 exe。
- 数据库/MySQL、Redis/Qdrant 仍由原服务管理；外部 AI 任务处理不由本助手自动启动。
- 等待请求完成不能替代幂等、事务修复或备份；断电、系统强制结束、长连接、持续高负载和大规模师生并发未在本轮通过。
- 原项目此前记录的权限、附件安全及弱网一致性专项仍需继续验证，不能因采用 Waitress 就宣称商业上线安全。
