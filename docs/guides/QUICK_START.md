# 快速启动指南

## 一键启动

### Windows用户
双击运行 `start.bat` 文件即可一键启动前后端服务。

### 手动启动步骤

如果一键启动失败，请按以下步骤手动启动：

#### 1. 启动后端
```bash
cd backend
python init_test_accounts.py
python run.py
```

#### 2. 启动前端（新开一个终端）
```bash
cd frontend
npm run dev
```

## 访问地址

- 前端：http://localhost:3000
- 后端：http://localhost:5000

## 常见问题

### 后端无法启动
- 检查Python是否安装：`python --version`
- 检查依赖是否安装：运行 `python install_deps.py`
- 检查端口5000是否被占用

### 前端无法连接后端
- 确保后端正在运行
- 检查浏览器控制台错误信息
- 确认后端地址是 http://localhost:5000

### 登录失败
- 确认测试账号已创建：运行 `python init_test_accounts.py`
- 检查用户名和密码是否正确
- 查看后端日志中的错误信息
