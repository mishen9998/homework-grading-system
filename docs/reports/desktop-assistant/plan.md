# 桌面启动助手实施计划

2026-09-18；单助手顺序执行，保留旧流水线。范围仅限当前项目的一键本地运行，不扩展为公网发布或系统级后台服务。

1. 原生窗口：一键启动、打开系统、安全停止、运行状态、日志/迁移指南；双击默认启动，重复打开不重复起服务。
2. 运行模式：Waitress + Vue 构建产物，同源本机入口；关闭 debug/自动建表；沿用本地私有配置，不在代码中写密码。
3. 生命周期：依赖/数据库/迁移/端口检查；仅管理自己创建的进程；停止时等待正在执行的请求，失败明确反馈；不启动付费 AI worker、不重置数据库、不强杀占用端口的进程。
4. 交付根目录中文启动文件与说明；覆盖路径含中文、缺依赖、端口占用、重复启动、启动失败、静态资源、接口健康与启停回归。

假设：用户要的是项目控制面板，不是通用聊天机器人；不安装开机自启或 Windows 服务。Python/Node/MySQL 首次环境安装不静默代办。程序修改后首次运行按需构建前端，日常使用不运行 Vite 开发服务。

验收：测试、真实本机服务启停及原生窗口检查，结果另记验证报告；不自称独立第三方验收。
